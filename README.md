# AI Building Lab

**A cada sessão, uma tendência quente de IA vira um projeto pequeno, funcional e fácil de demonstrar.** Este é o laboratório público do Lucas para explorar vibe coding, skills, MCPs, agentes, automações e ideias de SaaS enquanto testa ferramentas de desenvolvimento com IA em situações reais.

O ciclo tem 14 projetos. Os temas são escolhidos no dia: pesquisamos o que está chamando atenção, avaliamos ideias com fontes atuais e selecionamos uma para transformar em algo que as pessoas possam experimentar.

## Como funciona

1. Pesquisamos tendências recentes de IA e apresentamos até três ideias com fontes e datas.
2. Escolhemos uma ideia que caiba em uma sessão e resolva um problema claro.
3. Construímos, testamos e documentamos uma demonstração curta.
4. Registramos o projeto aqui e comparamos a experiência de uso das ferramentas.

## O que estou explorando

- Criar com IA: vibe coding, protótipos e produtos SaaS pequenos.
- Criar skills, agentes, integrações MCP e automações úteis.
- Descobrir quais ferramentas e modelos se encaixam melhor em cada tipo de trabalho.

Cada projeto registra as ferramentas utilizadas e mostra o que foi realmente verificado. Protótipos, exemplos simulados e integrações reais são identificados com clareza.
